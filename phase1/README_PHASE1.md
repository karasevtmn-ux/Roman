# Фаза 1 — Технический каркас desktop-приложения

## Что сделано
- Подготовлен минимальный каркас приложения `justice_watcher`.
- Добавлена конфигурация приложения (пути, SMTP и локальный config-файл).
- Добавлена локальная SQLite-база и таблица `case_links`.
- Добавлено рабочее окно PySide6 с таблицей ссылок и базовым CRUD:
  - добавление ссылки,
  - удаление выбранной ссылки,
  - загрузка ссылок из SQLite при старте.
- Добавлено окно «Настройки SMTP» с локальным сохранением параметров.

## Структура
- `src/justice_watcher/main.py` — точка входа.
- `src/justice_watcher/config.py` — настройки приложения и сохранение локального конфига.
- `src/justice_watcher/db.py` — инициализация SQLite, модель `CaseLink`, репозиторий.
- `src/justice_watcher/ui/main_window.py` — UI (главное окно + диалоги).

## Как запускать (после установки зависимостей)
```bash
pip install -r requirements.txt
PYTHONPATH=src python -m justice_watcher.main
```
